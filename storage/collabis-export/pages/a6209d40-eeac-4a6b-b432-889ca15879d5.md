# Классификация
контейнеров по размерам

Для идентификации контейнеров разработан международный стандарт ISO 6346:1995, нормирующий размеры, назначение и конструкционные особенности. По размерам контейнеры подразделяют на:
стандартные 20-футовые — 6058х2440х2600 мм (ДхШхВ);
40-футовые — 12192х2440х2600 мм;
высокие 40-футовые — 12192х2440х2900 мм;
45-футовые — 13600х2500х2900 мм.
