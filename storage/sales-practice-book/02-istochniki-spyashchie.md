# Источники клиентов и «спящие»

Материал к **Дню 4: Клиентская база**. Цель дня — не «найти один контакт», а выстроить поток касаний.

## Цель

- Привлекайте новых клиентов. До статуса «постоянный» часто проходит **не меньше полугода**.
- Поддерживайте контакт со всеми, с кем уже говорили: «тишина» в CRM — это потерянная выручка.

## Почему это важно

- Новые клиенты сами не приходят.
- Клиенты, с которыми давно не связывались, часто дают сделку быстрее «холодных с нуля».
- Продавцы с дисциплиной поиска закрывают больше сделок.

## Где искать

| Источник | Что делать |
| --- | --- |
| CRM компании | Спящие, незакрытые лиды, бывшие заказчики без касания 30+ дней |
| Профильные транспортные биржи | Регулярный мониторинг направлений |
| Участники отраслевых выставок | Списки / визитки → задачи в CRM |
| Таможенные / отраслевые базы | Импортёры и экспортёры по вашим коридорам |
| Поиск по ключевым запросам | Производители, дистрибьюторы, сети |
| Сайты крупных экспедиций / рейтинги | Понимание рынка и «запасных» каналов |
| Сайты производителей | Прямой грузовладелец |

Адаптируйте список под ваши направления и продуктовую матрицу Автоальянса.

## Что сделать сегодня (чек-лист)

1. Составить список **20** потенциальных контактов (телефон / ЛПР / источник).
2. Отметить отдельно **спящих**: был контакт, нет результата или давно не звонили.
3. По каждому: цель звонка (узнать / просчёт / вернуть) и 2–3 факта о компании.
4. План разговора на бумаге или в задаче CRM **до** набора номера.
5. После звонка — сразу задача на следующий контакт.

## Правило РОПа

Нет следующего шага в CRM = касание не состоялось.
