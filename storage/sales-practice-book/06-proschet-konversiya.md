# Просчёт запроса и конверсия

Этап между интересом и заказом. Без дисциплины просчёта «воронка» — иллюзия.

## Цель

- Конвертировать запрос в заказ.
- Понять потенциал клиента (география, проектность, ставки).
- Иметь обратную связь и ориентир рынка.

## Что всегда уточнять перед ставкой

- Маршрут (точные населённые пункты погрузки/выгрузки)
- Вес, объём, характер груза, стоимость (если влияет на условия)
- Таможенное оформление / режим / особые требования
- Даты, окна склада, работа в выходные
- Условия оплаты и ожидания по сервису

Неполная вводная = слабый просчёт = «дорого» без шанса сравнить яблоки с яблоками.

## Что делать в CRM

1. Зафиксировать запрос (лид / заказ / комментарий — по вашему процессу).
2. Отслеживать обратную связь от клиента.
3. Анализировать конверсию запросов в заказы (см. `➗ Конверсия`).
4. Периодически возвращаться к клиенту с разбором его запросов за период — это повод для диалога.

## Правило

Каждый просчёт без статуса «почему не взяли» — потерянное обучение для вас и для команды.
