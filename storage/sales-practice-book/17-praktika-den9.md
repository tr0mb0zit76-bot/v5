# Практика дня: банк возражений (День 9)

Учебный день. Не копируйте сюда весь банк — работайте с разделом:

**`🎯 Работа с возражениями`**

## Задание дня

1. Выберите **один** тип: секретарь / цена / конкуренты / «подумаю» / нет потребности / недоверие.  
2. Прочитайте страницу раздела.  
3. Сделайте **3** звонка с установкой отработать этот тип.  
4. Запишите в CRM: какое возражение было и какой следующий шаг.  
5. На планёрке разберите один звонок.
