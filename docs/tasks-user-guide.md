# Задачи — инструкция для пользователя

Документ описывает работу с задачами в CRM: создание, статусы, чеклист, комментарии, вложения и массовые действия.

Для визуальной доски см. [Канбан](kanban-user-guide.md).

---

## 1. Как открыть раздел

1. В меню **Планирование → Задачи** (или пункт **Задачи** в боковой панели).
2. Откроется таблица задач с поиском и фильтрами.
3. **Двойной клик** по строке — карточка задачи.
4. Кнопка **Создать задачу** — новая задача в модальном окне.

> Раздел доступен при области видимости **«Задачи»**. Без неё задачи можно только просматривать (например, на Канбане).

---

## 2. Минимально необходимое для создания

| Поле | Обязательно | По умолчанию |
| --- | --- | --- |
| **Название** | Да | — |
| **Приоритет** | Да | Средний |
| **Ответственный** | Да | Текущий пользователь |
| **Статус** | Нет | Новая |
| **Срок** | Нет | — |
| **SLA** | Нет | Совпадает со сроком |
| **Лид / контрагент** | Нет | — |

Номер задачи присваивается автоматически: **TSK-ГГММДД-001** (и далее по порядку за день).

---

## 3. Приоритеты и статусы

### Приоритеты

| Приоритет | Когда использовать |
| --- | --- |
| **Низкий** | Фоновые дела без жёсткого срока |
| **Средний** | Обычная рабочая задача |
| **Высокий** | Важно выполнить в ближайшее время |
| **Критичный** | Срочно; в таблице и на Канбане помечается «срочно» |

### Статусы

| Статус | Смысл |
| --- | --- |
| **Новая** | Создана, ещё не взята в работу |
| **В работе** | Исполнитель работает |
| **На проверке** | Ждёт проверки руководителя |
| **Завершена** | Выполнена (фиксируется дата завершения) |
| **Отложена** | Временно приостановлена |

Статус можно менять: в форме редактирования, **прямо в таблице**, через **контекстное меню** строки, **массово** или на **Канбане** перетаскиванием.

---

## 4. Таблица задач

### Колонки

Номер, название, статус, приоритет, ответственный, срок, лид, прогресс чеклиста (выполнено / всего).

### Поиск и фильтры

- **Поиск** — по номеру, названию, статусу, ответственному, лиду.
- Быстрые фильтры: **Все**, **Срочные**, **В работе**, **На проверке**, **Просроченные**.
- **Ответственный** — если в системе несколько пользователей.

Просроченные по **сроку** (задача не завершена) подсвечиваются.

### Контекстное меню (ПКМ по строке)

- Открыть карточку
- **В работу**, **На проверку**, **Завершить**
- **Перенести срок…**
- **Назначить ответственного…** (при правах руководителя)

---

## 5. Карточка задачи

Открывается двойным кликом или по ссылке с параметром `?task=ID`.

### Что видно

Описание, статус, приоритет, срок, **SLA**, привязка к лиду и контрагенту.

### Действия

| Кнопка | Действие |
| --- | --- |
| **Редактировать** | Изменить поля задачи |
| **Завершить** | Перевести в «Завершена» |
| **Завершить и создать новую** | Закрыть текущую и создать копию со статусом «Новая» |
| **Перенести срок** | Новая дата выполнения |

### Чеклист

- Доступен **только в карточке** (не при создании).
- Введите текст пункта → **Добавить**.
- Отметка чекбокса — выполнено / не выполнено.
- В таблице отображается **выполнено / всего**.

### Комментарии

- Текст обязателен → **Отправить**.
- **Ответственному** приходит уведомление (если комментарий оставил не он).
- Комментарии попадают в **историю** задачи.

### Вложения

- **Выбрать файл** → **Загрузить**.
- Форматы: PDF, DOC/DOCX, XLS/XLSX, PNG, JPG/JPEG, WEBP, TXT.
- Скачивание по имени файла; **Удалить** — при праве редактирования.

### История

Все изменения полей, комментарии и операции с вложениями.

---

## 6. Массовые действия

1. Отметьте задачи **чекбоксами** в таблице.
2. Выберите действие:

| Действие | Результат |
| --- | --- |
| **Закрыть выбранные** | Статус «Завершена» |
| **Назначить выбранные** | Смена ответственного (руководители / «все задачи») |
| **Применить статус** | Единый статус для выбранных |
| **Перенести срок** | Общий новый срок |

---

## 7. SLA (контрольный срок)

- Поле **SLA** в форме; подсказка: *если пусто — как срок*.
- Если SLA не задан явно, он **равен сроку выполнения**.
- В карточке при нарушении SLA — **красная метка**.
- **Нарушение**: открытая задача, дата SLA в прошлом.
- Руководителям (admin, supervisor) уходит уведомление **«Просрочен SLA по задаче»** (фоновая проверка раз в час).
- На **дашборде** — счётчик задач с просроченным SLA.
- При **переносе срока** SLA пересчитывается (если не задан отдельно — следует за новым сроком).

## 8. Связь с другими модулями

### Лид

- Задачу можно привязать к лиду.
- Смена статуса задачи может **синхронизировать статус лида**:

| Статус задачи | Статус лида |
| --- | --- |
| Новая | Новый |
| В работе | Квалификация |
| На проверке | Переговоры |
| Завершена | Конвертирован |
| Отложена | Отложен |

### Автосоздание из бизнес-процесса

При переходе лида на этап воронки система может автоматически создать задачу (если в настройках этапа включено **«Автосоздание задачи»**).

### Быстрое создание

Командная строка CRM → **Создать задачу**.

## 9. Права

| Настройка | Возможности |
| --- | --- |
| Область **«Задачи»** | Создание, редактирование, массовые действия |
| Только **свои** | Видны и редактируются только задачи, где вы ответственный |
| **Все** задачи | Полный реестр; назначение другим сотрудникам |
| Без «Задачи», но с **Канбан** | Только просмотр доски |

---

## 10. Типичные сценарии

**Поручение менеджеру.** Создать → название + ответственный + срок → Сохранить.

**Контроль этапа лида.** Привязать лид → менять статус задачи по ходу работы.

**Повторяющаяся работа.** Завершить и создать новую — для цикличных касаний.

**Контроль SLA.** Задать SLA отдельно от срока → следить за меткой в карточке.

---

## 11. Частые вопросы

**Не могу назначить задачу коллеге.** Нужна видимость «все задачи» или права руководителя.

**Нет чеклиста при создании.** Чеклист добавляется только в карточке после сохранения.

**Задача не видна.** Проверьте фильтр «Ответственный» и область «свои / все».
