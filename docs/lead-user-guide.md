# Лиды — инструкция для менеджера

Пошаговое руководство для ежедневной работы.  
**Полное описание механизма** (статусы, бизнес-процесс, напоминания, автоматика): [leads-mechanism.md](./leads-mechanism.md).

См. также: [Мастер заказов](order-wizard-user-guide.md) — после конвертации лида.

---

## Зачем вести лид в CRM, а не «в голове» и в чатах

Лид — это входящая возможность **до заказа**: звонок, письмо, заявка, знакомство. Грамотная работа с карточкой даёт менеджеру не отчёт для руководителя, а **свою** операционную выгоду.

| Если вести лид                                                      | Что получаете вы                                                                                                                          |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Фиксируете тему, клиента и **следующий контакт** сразу после звонка | Сделка не растворяется в потоке. Утром открываете **«Требует внимания»**, а не вспоминаете, кому обещали перезвонить                      |
| Заполняете маршрут, груз, ставки и котировки в карточке             | При выигрыше **конвертация** переносит данные в заказ. Не набиваете заявку второй раз                                                     |
| Записываете несколько ставок перевозчиков и выбираете одну          | Видите, **у кого дешевле**, какая маржа и кого подставить в исполнители — без переписки «а кто сколько сказал»                            |
| Смотрите блок **«Что дальше»** и playbook этапа                     | Система говорит, какой шаг сейчас важнее: добрать ЛПР, посчитать, отправить КП, перейти этап                                              |
| Отправляете КП из вкладки **Коммерческое**                          | Клиент получает аккуратное письмо с вложением; статус сам уходит в «КП отправлено»; если ответа нет — придёт задача, а не «забыли»        |
| Указываете **причину** выигрыша или отказа                          | Блок **«Коучинг по итогам»** показывает ваши дыры (нет ЛПР, цена, пропал контакт) — это разбор **ваших** сделок, не абстрактная аналитика |
| Переносите ЛПР и бюджет в **портрет** контрагента                   | Следующий запрос от того же клиента открывается уже с контекстом: с кем говорить и на какие суммы рассчитывать                            |
| Закрываете проигрыш с флагом                                        | Открытые задачи по лиду снимаются; система предлагает **задачу «на будущее»** — клиент не вычёркивается навсегда                          |

Коротко: заполненный лид экономит время на следующем касании, на КП и на заказе. Пустая карточка — это повторный сбор тех же деталей под давлением срока.

## 1. Как открыть раздел и с чего начать день

1. В боковом меню выберите **Лиды**.
2. Откроется **реестр** — таблица с поиском, фильтрами, сохранёнными представлениями и плотностью строк.
3. **Двойной клик** по строке открывает **карточку в модальном окне** (реестр остаётся на фоне).
4. **Добавить** — новый лид в том же окне.
5. **Голосом** — надиктовать или вставить текст после звонка (маршрут, груз, контакт); система создаст черновик лида, его можно поправить и сохранить.

На странице **Лиды** (когда карточка закрыта) могут быть две панели:

- **«Требует внимания»** — просроченный этап, пропущенный контакт, нет ответа на письмо. Это **очередь на сегодня**, не декорация.
- **«Коучинг по итогам»** — доля выигрышей и типичные ошибки по **закрытым** сделкам за период. Смотрите после разбора живой очереди.

> Раздел доступен при области видимости **«Лиды»** в роли.

### Реестр — быстрые возможности

| Возможность                   | Зачем вам                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| **Inline-редактирование**     | Сменить статус, источник или ответственного без открытия карточки                          |
| **Массовые действия**         | То же для нескольких строк или удаление                                                    |
| **Сохранённые представления** | Свой набор колонок и фильтров (например, «мои в переговорах»)                              |
| **Контекстное меню (ПКМ)**    | Открыть, **создать на основании** (повтор похожей заявки без копирования вручную), удалить |

## 2. Минимум для сохранения

| Поле                  | Обязательно                                 |
| --------------------- | ------------------------------------------- |
| **Тема**              | Да, уникальная                              |
| **Ответственный**     | Да (по умолчанию — вы)                      |
| **Процесс (воронка)** | Да, если в системе включены бизнес-процессы |

При частично заполненных **маршруте** или **грузе** проверяются обязательные поля этих блоков.

### Быстрый сценарий «за минуту»

1. **Добавить** (или **Голосом** после звонка) → вкладка **Основное**.
2. **Тема** + **контрагент** (поиск от 2 символов; нет в базе — создайте из карточки).
3. **Сохранить**.
4. Сразу поставьте **следующий шаг** (задачу) или дату следующего контакта — иначе лид «зависнет», и вы сами себе устроите сюрприз в панели внимания.

## 3. Какая воронка — такой набор вкладок

Набор вкладок и кнопок в шапке зависит от **бизнес-процесса**.

### Разовая перевозка (`transport-intake` и аналогичный полный профиль)

| Вкладка          | Для чего                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| **Основное**     | Статус, процесс, «Что дальше», клиент, квалификация, следующий шаг                             |
| **Маршрут**      | Плечи, точки, перевозчики по плечам                                                            |
| **Груз**         | Позиции груза                                                                                  |
| **Предрасчёт**   | Импорт / параллельный ввоз: товары, услуги, таможня → итог в цену клиента                      |
| **Финансы**      | Цена клиента и перевозчика, формы оплаты, **котировки**, ориентир по похожим перевозкам, маржа |
| **Документы**    | Вложения                                                                                       |
| **Коммуникации** | Звонки, заметки, лента событий и писем                                                         |
| **Коммерческое** | КП (DOCX и HTML), предпросмотр, отправка по e-mail                                             |

В шапке после сохранения: **На биржу**, **Сколько влезет?**, **Конвертировать в заказ**.

### Подписание договора (`contract-signing`)

Вкладки: **Основное**, **Документы**, **Коммуникации**, **Коммерческое**. Без маршрута, груза, предрасчёта и финансов — это не заявка на рейс, а согласование договора.

### Знакомство с клиентом (`client-acquaintance`)

Те же короткие вкладки, что у договора. Когда клиент «созрел» до конкретной перевозки — кнопка **«Лид по перевозке»**: создаётся связанный транспортный лид с контрагентом и тем, что уже собрали в знакомстве. Не плодите второй лид вручную.

Вкладки **Коммерческое**, **Документы**, **Предрасчёт** и котировки доступны только у **уже сохранённого** лида.

## 4. Шапка карточки

| Кнопка                     | Когда видна                                     | Зачем вам                                             |
| -------------------------- | ----------------------------------------------- | ----------------------------------------------------- |
| **Сохранить**              | Всегда                                          | Запись изменений                                      |
| **На биржу**               | Воронка перевозки + область `load_board`        | Выставить груз, не копируя маршрут                    |
| **Сколько влезет?**        | Воронка перевозки + область модуля              | Прикинуть загрузку по данным лида                     |
| **Конвертировать в заказ** | Воронка перевозки, выбран **контрагент**        | Заказ без повторного ввода; статус лида → **Выигран** |
| **Лид по перевозке**       | Воронка «Знакомство», ещё не создавали дочерний | Переход от знакомства к рабочей заявке                |

---

## 5. Основное — здесь решается, не «забудете ли вы» лид

- **Полоска статусов** — общая стадия (Новый → … → Переговоры; исходы: Выигран / Закрыт без сделки / Отложен). В реестре «Сбор деталей» отображается как **«Квалификация»**.
- **«Что дальше»** — что сделать в первую очередь; клик ведёт на нужную вкладку. Если к этапу привязан скрипт — кнопка **«По скрипту»**.
- **Бизнес-процесс** — регламент: цель этапа, срок, playbook, переход **Перейти**. Просроченный этап попадает в «Требует внимания».
- **Квалификация** — поля **ЛПР** и **бюджет**. ЛПР подставляется из карточки контрагента. Без ЛПР вы часто проигрываете «в никуда»: коучинг это потом покажет отдельно.
- Кнопка **«Перенести ЛПР и бюджет в портрет»** — чтобы следующий лид по этому клиенту открывался уже с контекстом.
- **Следующий шаг** — задача по лиду. Если указан срок, обновляется **следующий контакт**. Нужен доступ к **Задачам**.

При закрытии без сделки система отменяет открытые задачи по лиду и предлагает создать задачу **на будущее** (поддержать контакт). Соглашайтесь, если клиент живой.

## 6. Маршрут, котировки, предрасчёт, финансы

**Маршрут** — одно или несколько **плеч**: точки погрузки/выгрузки и при необходимости перевозчик с ориентиром по ставке. Эти исполнители уедут в заказ при конвертации.

**Котировки перевозчиков** (вкладка **Финансы**, после сохранения лида): несколько ставок на один запрос (телефон, АТИ, биржа). Кнопка **«Выбрать»** подставляет ставку в цену перевозчика, форму оплаты и первого исполнителя. Остальные котировки помечаются как отклонённые — вы не потеряете историю «кто сколько дал».

**Похожие перевозки** (там же, если есть выборка по маршруту): min / среднее / max ставки заказчика и перевозчика из истории. Ориентир для переговоров, не приказ.

**Ожидаемая маржа** считается из цены клиента минус цена перевозчика — видно до отправки КП.

**Предрасчёт** — для импорта: товары (ТН ВЭД, валюта инвойса), услуги (логистика подтягивается из плеч), таможня. **«Применить к финансам»** переносит итог в цену клиента. При конвертации снимок сохраняется в заказе.

## 7. КП и заказ

**КП:** вкладка **Коммерческое** → шаблон (DOCX или HTML) → черновик → предпросмотр / PDF → отправить по e-mail. Письмо и статус «КП отправлено» появляются сами; ответ клиента (если почта синхронизирована) попадёт в **Коммуникации**.

**Заказ** (воронка перевозки): **Конвертировать в заказ** → контрагент, маршрут, груз, финансы, выбранный перевозчик и снимок предрасчёта. Статус лида → **Выигран**. Один лид — один заказ: повторное нажатие откроет уже созданный.

Без контрагента кнопка неактивна — это защита от «заказа ни на кого».

## 8. Типовые сценарии

| Ситуация                   | Действия                                                                                | Что это даёт                                                            |
| -------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Входящий звонок            | **Голосом** или **Добавить** → тема + контрагент → сохранить → задача «Перезвонить»     | Карточка и напоминание есть через минуту, детали не держатся в блокноте |
| Расчёт и КП                | Маршрут + груз → цена (или предрасчёт / выбранная котировка) → Коммерческое → отправить | Клиент видит цифру; вы видите маржу; система следит за ответом          |
| Несколько перевозчиков     | Финансы → котировки → **Выбрать** лучшую                                                | Сравнение ставок в одном месте, исполнитель в заказе уже тот            |
| Импорт / параллельный ввоз | Плечи → Предрасчёт → применить к финансам → КП                                          | Итог для клиента считается из товаров и логистики, а не «с потолка»     |
| Знакомство без рейса       | Процесс «Знакомство» → скрипт / портрет → **Лид по перевозке**                          | Не смешиваете «познакомились» и «везём фуру»                            |
| Выигрыш                    | Конвертировать в заказ                                                                  | Заявка уже наполовину заполнена                                         |
| Проигрыш                   | Закрыт без сделки + флаг причины (+ задача на будущее)                                  | Честный разбор и шанс вернуться к клиенту                               |
| Утро                       | Панель **«Требует внимания»** сверху вниз                                               | Сначала горящее, потом новые                                            |

## 9. Частые вопросы

| Проблема                                      | Решение                                                                                                     |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Не сохраняется                                | Уникальная тема, ответственный, процесс; при частичном маршруте/грузе — обязательные поля блоков            |
| Нет «Коммерческое» / «Предрасчёт» / котировок | Сначала сохраните лид; проверьте профиль воронки                                                            |
| Конвертация серая или кнопки нет              | Нужен контрагент; кнопка есть у воронки **перевозки**, не у «Знакомства» и не у «Договора»                  |
| Не вижу чужие лиды                            | У роли видимость «только свои»                                                                              |
| Задача «Нет ответа на КП»                     | Связаться с клиентом                                                                                        |
| Завершил задачу — лид не «Выигран»            | Так и задумано: выигрыш только через конвертацию или явный исход                                            |
| Нет вкладки «Маршрут»                         | Процесс «Подписание договора» или «Знакомство с клиентом»                                                   |
| После отказа пропали задачи                   | Открытые задачи по лиду отменяются; создайте предложенную задачу «на будущее», если контакт стоит сохранить |
