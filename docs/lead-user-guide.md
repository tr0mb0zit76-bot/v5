# Лиды — краткая инструкция

Пошаговое руководство для ежедневной работы.  
**Полное описание механизма** (статусы, бизнес-процесс, напоминания, автоматика): [leads-mechanism.md](./leads-mechanism.md).

См. также: [Мастер заказов](order-wizard-user-guide.md) — после конвертации лида.

---

## 1. Как открыть раздел

1. В боковом меню выберите **Лиды**.
2. Откроется **реестр** — таблица лидов с поиском, фильтрами, сохранёнными представлениями и настройкой плотности строк.
3. **Двойной клик** по строке открывает **карточку в модальном окне** (не отдельная страница).
4. **Добавить** — новый лид в том же модальном окне.

На странице **Лиды** (когда карточка закрыта) могут отображаться:

- **«Требует внимания»** — просроченный этап, пропущенный контакт, нет ответа на письмо;
- **Outcome Intelligence** — коучинг по закрытым сделкам за период (win rate, типичные ошибки).

> Раздел доступен при включённой области видимости **«Лиды»** в роли.

### Реестр — быстрые возможности

| Возможность | Зачем |
| --- | --- |
| **Inline-редактирование** | Статус, источник и ответственный прямо в ячейке (если разрешено ролью) |
| **Массовые действия** | Смена статуса / источника / ответственного или удаление для выбранных строк |
| **Сохранённые представления** | Закрепить набор колонок и фильтров под свой сценарий |
| **Контекстное меню** | ПКМ по строке: открыть, создать на основании, удалить |

## 2. Минимум для сохранения

| Поле | Обязательно |
| --- | --- |
| **Тема** | Да, уникальная |
| **Ответственный** | Да (по умолчанию — вы) |
| **Процесс (воронка)** | Да, если в системе включены бизнес-процессы |

При частично заполненных **маршруте** или **грузе** проверяются обязательные поля этих блоков.

### Быстрый сценарий «за минуту»

1. **Добавить** → **Основное**.
2. **Тема** + при необходимости **контрагент** (поиск от 2 символов).
3. **Сохранить**.

---

## 3. Вкладки карточки

Набор вкладок зависит от **бизнес-процесса** лида.

### Стандартный профиль (разовая перевозка и аналоги)

| Вкладка | Для чего |
| --- | --- |
| **Основное** | Статус, процесс, «Сейчас», клиент, квалификация, следующий шаг |
| **Маршрут** | Плечи перевозки, точки маршрута, перевозчики по плечам |
| **Груз** | Позиции груза |
| **Предрасчёт** | Импорт / параллельный ввоз: товарные строки, услуги, таможня, итог в цену клиента |
| **Финансы** | Цена, формы оплаты, маржа |
| **Документы** | Вложения к лиду |
| **Коммуникации** | Звонки, заметки, лента событий |
| **Коммерческое** | КП (DOCX и HTML), отправка по e-mail |

### Профиль «Подписание договора»

У процесса с профилем **contract-signing** только три вкладки: **Основное**, **Документы**, **Коммуникации** — без маршрута, груза, предрасчёта и коммерции.

Вкладки **Коммерческое**, **Документы**, **Предрасчёт** и часть действий доступны только у **уже сохранённого** лида.

---

## 4. Шапка карточки

После сохранения лида в шапке доступны:

| Кнопка | Назначение |
| --- | --- |
| **Сохранить** | Запись изменений |
| **На биржу** | Перейти в модуль биржи с контекстом лида (нужна область `load_board`) |
| **Сколько влезет?** | Открыть калькулятор загрузки с данными лида (область `modules_how_much_fits` или `modules`) |
| **Конвертировать в заказ** | Создать заказ из лида (нужен **контрагент**) |

---

## 5. Основное — главное

- **Полоска статусов** — общая стадия сделки (Новый → … → Переговоры; исходы: Выигран / Закрыт без сделки / Отложен). В реестре статус «Сбор деталей» отображается как **«Квалификация»**.
- **«Сейчас»** — что сделать в первую очередь; клик по действию ведёт на нужную вкладку.
- **Бизнес-процесс** — регламент компании: этап, срок, переход **Перейти**.
- **Квалификация в интерфейсе** — поля **ЛПР** и **бюджет**; ЛПР подставляется из карточки контрагента при выборе клиента.
- **Следующий контакт** и блок **Следующий шаг** (задача).
- При закрытии без сделки или на проигрышном этапе — **структурированная причина** (флаг + при необходимости уточнение).

Подробнее: [разделы 4–11 в leads-mechanism.md](./leads-mechanism.md).

## 6. Маршрут и предрасчёт (кратко)

**Маршрут** — одно или несколько **плеч** (leg): у каждого плеча свои точки погрузки/выгрузки и при необходимости перевозчик с ориентиром по ставке.

**Предрасчёт** — для сделок с импортом: строки товаров (ТН ВЭД, валюта инвойса), услуги (логистика подтягивается из плеч), таможенные начисления. Кнопка **«Применить к финансам»** переносит итог в цену клиента. При конвертации снимок предрасчёта сохраняется в заказе.

---

## 7. КП и заказ

**КП:** вкладка **Коммерческое** → шаблон (DOCX или HTML) → черновик → предпросмотр / PDF → отправить по e-mail (нужен сохранённый лид).

**Заказ:** **Конвертировать в заказ** → переносятся контрагент, маршрут, груз, финансы, перевозчики по плечам и снимок предрасчёта; статус лида → **Выигран**.

---

## 8. Типовые сценарии

| Ситуация | Действия |
| --- | --- |
| Входящий звонок | Тема + контрагент → сохранить → задача «Перезвонить» |
| Расчёт и КП | Маршрут + груз → цена (или предрасчёт → финансы) → Коммерческое → отправить |
| Импорт / параллельный ввоз | Маршрут + плечи → Предрасчёт → применить к финансам → КП |
| Выигрыш | Конвертировать в заказ |
| Проигрыш | Закрыт без сделки + причина (флаг) |
| Публикация на биржу | Сохранить лид → **На биржу** |

---

## 9. Частые вопросы

| Проблема | Решение |
| --- | --- |
| Не сохраняется | Уникальная тема, ответственный, процесс |
| Нет «Коммерческое» / «Предрасчёт» | Сначала сохраните лид; проверьте профиль бизнес-процесса |
| Конвертация серая | Выберите контрагента |
| Не вижу чужие лиды | У роли видимость «только свои» |
| Задача «Нет ответа на КП» | Связаться с клиентом — см. [напоминания](./leads-mechanism.md#8-напоминания-nudges-и-задачи) |
| Завершил задачу — лид не «Выигран» | Так и задумано: завершение задачи не переводит лид в выигрыш автоматически |
| Нет вкладки «Маршрут» | Процесс с профилем «Подписание договора» |
