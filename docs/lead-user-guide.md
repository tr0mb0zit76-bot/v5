# Лиды — инструкция для пользователя

Документ описывает, как вести входящую заявку в CRM: от создания лида до коммерческого предложения и конвертации в заказ.

См. также: [Мастер заказов](order-wizard-user-guide.md) — что происходит после конвертации лида.

---

## 1. Как открыть раздел

1. В боковом меню выберите **Лиды**.
2. Откроется реестр — таблица всех лидов с фильтрами и поиском.
3. **Двойной клик** по строке открывает карточку лида.
4. Кнопка **Добавить** создаёт новый лид.

> Раздел доступен, если в вашей роли включена область видимости **«Лиды»**.

---

## 2. Минимально необходимое для сохранения

Отдельного режима «черновик без проверок» нет — при первом сохранении система проверяет обязательные поля.

| Поле | Обязательно | Примечание |
| --- | --- | --- |
| **Тема лида** | Да | Должна быть уникальной среди всех лидов |
| **Статус** | Да | По умолчанию «Новый» |
| **Ответственный** | Да | По умолчанию — вы; смена доступна при праве назначать других |
| **Процесс (воронка)** | Условно | Обязателен, если в системе включены бизнес-процессы |

**Условно обязательные поля** (если блок уже заполнен):

- **Валюта** — если указана цена клиента.
- **Маршрут** — тип и адрес каждой добавленной точки.
- **Груз** — наименование, тип груза, признак опасного груза для каждой позиции.

### Быстрый сценарий «записать лид за минуту»

1. **Добавить** → вкладка **Основное**.
2. Укажите **Тему** (например, «Перевозка Москва — Казань, 20 т»).
3. При необходимости выберите **Контрагента** (поиск от 2 символов по названию, ИНН, телефону, email).
4. Нажмите **Сохранить**.

Маршрут, груз, КП и конвертацию можно дозаполнить позже.

---

## 3. Вкладки карточки лида

| Вкладка | Для чего |
| --- | --- |
| **Основное** | Статус, источник, ответственный, контрагент, цена, квалификация, бизнес-процесс, следующий шаг |
| **Маршрут** | Точки погрузки и выгрузки: адрес, дата, контакты |
| **Груз** | Позиции груза: вес, объём, упаковка, ТН ВЭД, опасный груз |
| **Коммуникации** | Звонки, письма, встречи, заметки и лента событий |
| **Коммерческое** | Шаблоны КП, черновики DOCX, отправка по e-mail, ссылка на заказ |

---

## 4. Вкладка «Основное»

### Контрагент

- Поиск по названию, ИНН, телефону или email (от **2 символов**).
- Кнопка **Новый контрагент** — быстрое создание без выхода из карточки (обязательно только **название**).

### Ключевые поля

| Поле | Назначение |
| --- | --- |
| **Источник** | Откуда пришёл лид (входящий, сайт, рекомендация и т.д.) |
| **Плановая отгрузка** | Ориентир по срокам; при конвертации может стать датой заказа |
| **Тип перевозки** | FTL, LTL, контейнер, мультимодальная, авиа, ж/д |
| **Цена клиента** | Сумма и валюта — переносится в заказ при конвертации |
| **Следующий контакт** | Дата следующего касания |
| **Причина потери** | Для закрытых без сделки лидов |

### Квалификация (BANT)

Блок для оценки лида: потребность, срок, ЛПР, бюджет — помогает понять, готов ли лид к КП и сделке.

### Следующий шаг

После сохранения лида можно создать **задачу** с названием, сроком и ответственным. Если указан срок — обновится поле «Следующий контакт». Требуется доступ к модулю **Задачи**.

---

## 5. Статусы лида

| Статус | Когда использовать |
| --- | --- |
| **Новый** | Только что создан |
| **Квалификация** | Уточняем потребность и условия |
| **Просчёт** | Считаем ставку |
| **КП подготовлено** | Черновик КП создан (может выставиться автоматически) |
| **КП отправлено** | КП отправлено клиенту |
| **Переговоры** | Обсуждаем условия |
| **Конвертирован** | Создан заказ |
| **Закрыт без сделки** | Лид проигран |
| **Отложен** | Временно не работаем |

**Автоматические переходы:**

- Создание черновика КП → **КП подготовлено**
- Отправка КП по e-mail → **КП отправлено** (если до этого было «КП подготовлено»)
- Конвертация в заказ → **Конвертирован**
- Терминальный этап бизнес-процесса → **Конвертирован** или **Закрыт без сделки**

---

## 6. Бизнес-процесс (воронка)

Если модуль бизнес-процессов развёрнут:

1. При **создании** выберите **процесс** из списка активных воронок.
2. После сохранения лид встанет на **первый этап**.
3. На вкладке «Основное» отображаются: текущий этап, прогресс, срок этапа (просрочка подсвечивается), цепочка этапов.
4. **Перевести на этап** — выпадающий список + кнопка **Перейти**.
5. На некоторых этапах система **автоматически создаёт задачу** по сценарию (playbook).

В реестре видны колонки: процесс, этап, срок этапа, просрочен ли этап.

---

## 7. Вкладка «Коммерческое»

Доступна только для **сохранённого** лида.

### Подготовка КП

1. Шаблоны настраиваются в **Настройки → Шаблоны печати** (сущность: лид, группа: коммерческие).
2. Выберите **шаблон** в списке на вкладке.
3. Нажмите **Создать в карточке** — формируется черновик **DOCX**.
4. **Предпросмотр** и **скачивание** — из списка печатных форм.
5. **Отправить по e-mail** — письмо с вложением; получатели подставляются из e-mail контрагента.

Справа — **история КП** и блок **«Конвертирован в заказ»**, если заказ уже создан.

---

## 8. Конвертация в заказ

1. Сохраните лид и укажите **контрагента** (без него кнопка неактивна).
2. Нажмите **Конвертировать в заказ** в шапке карточки.
3. Система создаст **новый заказ** (или откроет уже существующий, если конвертация была раньше).
4. Переносятся: клиент, дата, примечания, **маршрут**, **груз**, **цена** и валюта.
5. Статус лида → **Конвертирован**; вы попадёте в **мастер заказа**.

---

## 9. Права и видимость

| Роль / настройка | Что видит пользователь |
| --- | --- |
| Только **свои** лиды | Лиды, где он ответственный |
| **Все** лиды | Весь реестр |
| Администратор | Полный доступ, назначение ответственного |

---

## 10. Типичные сценарии

**Входящий звонок.** Добавить → тема + контрагент (или новый) → сохранить → задача «Перезвонить» со сроком.

**Расчёт и КП.** Заполнить маршрут и груз → вкладка «Коммерческое» → шаблон → черновик → отправить по e-mail.

**Выигрыш.** Конвертировать в заказ → дозаполнить мастер заказа (перевозчик, финансы, документы).

**Проигрыш.** Статус «Закрыт без сделки» + **Причина потери**.

---

## 11. Частые вопросы

**Не сохраняется лид.** Проверьте уникальность **темы**, заполнение **ответственного** и выбор **процесса** (если процессы включены).

**Нет вкладки «Коммерческое».** Сначала сохраните лид.

**Кнопка «Конвертировать» серая.** Выберите контрагента на вкладке «Основное».

**Не вижу чужие лиды.** У вашей роли, скорее всего, видимость «только свои».
