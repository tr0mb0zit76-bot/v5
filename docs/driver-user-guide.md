# Водители — инструкция для пользователя

Документ описывает учёт водителей в автопарке: карточка, документы и выбор водителя в заказе.

См. также: [Авто](vehicle-user-guide.md), [Мастер заказов](order-wizard-user-guide.md).

---

## 1. Как открыть раздел

1. В меню **Автопарк → Водители**.
2. Откроется таблица водителей.
3. **Двойной клик** по строке — карточка водителя.
4. Кнопка **Добавить** — новый водитель.

> Раздел доступен при области видимости автопарка (как **Авто**).

---

## 2. Минимально необходимое для сохранения

| Поле | Обязательно | Примечание |
| --- | --- | --- |
| **Контрагент-перевозчик** | Да | К какому перевозчику привязан водитель |
| **ФИО** | Да | Полное имя; без него «Сохранить» неактивна |

**Необязательные поля:**

- Телефон
- Номер и категории водительского удостоверения
- Паспорт (серия, номер, кем выдан, дата)
- Заметки

Карточка — **один экран** (не пошаговый мастер): реквизиты + документы после сохранения.

---

## 3. Карточка водителя

### Шапка

- **Новый водитель** / **Карточка водителя**
- **Назад** — закрыть
- **Сохранить** — записать

### Перевозчик

- Поиск по **названию** и **ИНН** среди контрагентов типа **перевозчик** (от **2 символов**).
- **Сброс** — очистить выбор.

> **Важно:** перевозчик в карточке водителя должен совпадать с **перевозчиком на плече** в заказе — иначе водитель не появится в выпадающем списке.

### Реквизиты

| Поле | Назначение |
| --- | --- |
| **ФИО** | Фамилия, имя, отчество |
| **Телефон** | Контактный номер |
| **ВУ: номер** | Номер водительского удостоверения |
| **ВУ: категории** | Категории (B, C, CE и т.д.) |
| **Паспорт** | Серия, номер, кем выдан, дата выдачи |
| **Заметки** | Внутние комментарии |

---

## 4. Документы

Доступны **после первого сохранения** карточки.

### Типы документов

| Тип | Когда использовать |
| --- | --- |
| **Паспорт** | Скан/фото паспорта (по умолчанию) |
| **Водительское удостоверение** | Скан/фото ВУ |
| **Прочее** | Дополнительные файлы |

### Загрузка

- Drag-and-drop или **Выбрать файл**.
- Форматы: PDF, DOC/DOCX, XLS/XLSX, JPG/JPEG, PNG, WEBP.
- **Превью**, **скачивание**, **удаление** с подтверждением.

---

## 5. Таблица (реестр)

- **Поиск** по ФИО, телефону, перевозчику.
- Настройка колонок и плотности.
- **Двойной клик** — карточка.

В списках заказа водитель отображается как **ФИО** и при наличии **телефон**.

---

## 6. Привязка к заказу

### Где выбирается

**Мастер заказа** → **Маршрут** → исполнитель на плече → поле **«Водитель»** (рядом с **«Авто»**).

При **нескольких перевозчиках на плече** — отдельный водитель у каждого слота.

### Порядок действий

1. Выберите **перевозчика** на плече.
2. Поле **«Водитель»** активируется.
3. В списке — водители с **тем же контрагентом-перевозчиком**.
4. Можно оставить **«—»** (необязательно).
5. **Сохраните заказ**.

### Проверки при сохранении

- Водитель не найден — ошибка.
- Перевозчик водителя ≠ перевозчик на плече — *«Водитель должен быть привязан к выбранному контрагенту-перевозчику»*.

### Связка «Авто + Водитель»

На одном плече можно указать и **Авто**, и **Водителя** независимо: оба необязательны, но оба фильтруются по одному перевозчику.

---

## 7. Дополнительные возможности

| Модуль | Связь |
| --- | --- |
| **Рейсы** | Назначение водителя на рейс |
| **Портал перевозчика** | Перевозчик загружает документы водителя по заказу |
| **Печатные формы** | Подстановка ФИО, телефона, данных ВУ |

---

## 8. Типичные сценарии

**Новый водитель перевозчика.** Добавить → перевозчик + ФИО + телефон → Сохранить → загрузить паспорт и ВУ.

**Заказ со своим парком.** Перевозчик = ваша компания → **Свой транспорт** → выбрать **Авто** и **Водителя**.

**Водитель сменил перевозчика.** Обновите **контрагента-перевозчика** в карточке или создайте новую запись.

---

## 9. Частые вопросы

**Нет водителя в списке заказа.** Выберите перевозчика; в карточке водителя должен быть тот же перевозчик.

**Сохранить неактивна.** Заполните **ФИО** и **перевозчика**.

**Документы недоступны.** Сначала сохраните карточку один раз.

**Один человек у двух перевозчиков.** Создайте **две карточки** с разными перевозчиками (если он работает на обоих).
