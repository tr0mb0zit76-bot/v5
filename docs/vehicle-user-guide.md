# Авто (транспортные средства) — инструкция для пользователя

Документ описывает учёт транспортных средств в автопарке: карточка ТС, документы и привязка к заказу.

См. также: [Водители](driver-user-guide.md), [Мастер заказов](order-wizard-user-guide.md) (блок «Свой транспорт»).

---

## 1. Как открыть раздел

1. В меню **Автопарк → Авто**.
2. Откроется таблица транспортных средств.
3. **Двойной клик** по строке — карточка ТС.
4. Кнопка **Добавить** — новое ТС.

> Раздел доступен при области видимости **«Водители»** / автопарк (как настроено в роли).

---

## 2. Минимально необходимое для сохранения

| Поле | Обязательно | Примечание |
| --- | --- | --- |
| **Владелец (контрагент)** | Да | Контрагент типа **перевозчик**; без него кнопка «Сохранить» неактивна |

**Необязательные поля:**

- Марка тягача / прицепа
- Гос. номер тягача / прицепа
- Заметки

Пошагового мастера нет — **одна форма** реквизитов и блок документов после первого сохранения.

---

## 3. Карточка ТС

### Шапка

- **Новое ТС** / **Карточка ТС**
- **Назад** — закрыть без сохранения (вернуться к списку)
- **Сохранить** — записать изменения

### Владелец

- Поиск по **названию** и **ИНН** среди контрагентов-**перевозчиков** (от **2 символов**).
- Выбор из выпадающего списка.
- **Сброс** — очистить выбор.

> **Важно для заказов:** владелец в карточке авто должен совпадать с **перевозчиком**, которого вы выбираете на плече маршрута в заказе. Иначе это ТС не появится в списке «Авто» в мастере заказа.

### Реквизиты

| Поле | Назначение |
| --- | --- |
| **Марка тягача** | Марка/модель седельного тягача |
| **Гос. номер тягача** | ГРЗ тягача |
| **Марка прицепа** | Марка/тип прицепа |
| **Гос. номер прицепа** | ГРЗ прицепа |
| **Заметки** | Внутние комментарии |

---

## 4. Документы

Доступны **только после первого сохранения** карточки. При создании показывается подсказка: сначала сохраните ТС.

### Типы документов

| Тип | Когда использовать |
| --- | --- |
| **ПТС** | Паспорт транспортного средства (по умолчанию) |
| **Договор аренды** | ТС в аренде |
| **Лизинг** | Лизинговый договор |
| **Страховка** | Полис ОСАГО / КАСКО |
| **Прочее** | Любые другие файлы |

### Загрузка

- Перетащите файл в зону загрузки или нажмите **Выбрать файл**.
- Форматы: PDF, DOC/DOCX, XLS/XLSX, JPG/JPEG, PNG, WEBP.
- В таблице вложений: **превью**, **скачивание**, **удаление** (с подтверждением).

---

## 5. Таблица (реестр)

- **Поиск** по ТС и владельцу.
- Настройка **плотности** и **колонок** (как в других таблицах CRM).
- **Двойной клик** — открыть карточку.

---

## 6. Привязка к заказу

### Где выбирается

**Мастер заказа** → вкладка **Маршрут** → блок исполнителя на плече → поле **«Авто»** (рядом с **«Перевозчик»** и **«Водитель»**).

Также при режиме **нескольких перевозчиков на одном плече** — у каждого слота свои «Авто» и «Водитель».

### Порядок действий

1. Выберите **перевозчика** на плече (или **Свой транспорт**, если используете свой автопарк).
2. Поле **«Авто»** станет активным.
3. При открытии списка подгружаются ТС, у которых **владелец = выбранный перевозчик**.
4. Можно оставить **«—»** — поле необязательно.
5. **Сохраните заказ**.

### Проверки при сохранении

- ТС не найдено в справочнике — ошибка.
- Владелец ТС ≠ перевозчик на плече — *«ТС должно принадлежать выбранному перевозчику»*.

### Где ещё используется

- **Рейсы** (Автопарк → Рейсы) — те же ТС.
- **Портал перевозчика** — перевозчик может загружать документы на ТС по заказу.
- **Печатные формы** заказа — подставляются данные выбранного ТС.

---

## 7. Типичные сценарии

**Новое ТС перевозчика.** Добавить → владелец-перевозчик → марка и номера → Сохранить → загрузить ПТС и страховку.

**Свой автопарк.** Владелец — контрагент вашей компании; в заказе включите **Свой транспорт** и выберите это ТС.

**Смена арендатора.** Смените **владельца** в карточке или создайте новую карточку под нового перевозчика.

---

## 8. Частые вопросы

**Не вижу ТС в заказе.** Сначала выберите перевозчика; владелец ТС в справочнике должен совпадать с ним.

**Нет блока документов.** Сохраните карточку хотя бы один раз.

**Не нахожу перевозчика в поиске.** Введите минимум 2 символа; контрагент должен быть типа **перевозчик**.
