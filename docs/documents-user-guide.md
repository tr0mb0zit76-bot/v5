# Документы

Инструкция по модулю **Реестр документов** в CRM: единая таблица документов по заказам, загрузка файлов, заявки и договоры из печатных форм, журнал ЭТрН.

---

## 1. Как открыть раздел

1. В боковом меню выберите **Документы**.
2. Откроется страница **Реестр документов** — таблица заказов с колонками по типам документов.
3. Кнопка **Добавить документ** — загрузка нового файла к выбранному заказу.

> Раздел доступен при области видимости **«Документы»**. Состав строк совпадает с доступом в **Заказы**: администратор видит все заказы, остальные — по правилам видимости (как в списке заказов).

---

## 2. Две вкладки реестра

| Вкладка | Назначение |
| --- | --- |
| **Все документы** | Полный реестр: счета, УПД, акты, заявки, договоры, транспортные документы, прочее |
| **Журнал ЭТрН** | Только заказы, у которых есть документ типа **ЭТрН** (электронная транспортная накладная) |

Счётчик в названии вкладки показывает количество строк в текущем наборе данных (до 400 последних заказов по фильтру сервера).

---

## 3. Таблица реестра

### Поиск и настройка

- **Фильтр по реестру** — быстрый поиск по номеру заказа, номеру заказчика или id (как в AG Grid на странице).
- **Колонки** — скрыть/показать и перетащить порядок; настройка сохраняется в браузере для вашего пользователя.
- **Плотность таблицы** — компактная / обычная / просторная.
- **Сбросить** — вернуть колонки к умолчанию.

### Основные колонки

| Колонка | Что показывает |
| --- | --- |
| **Номер заказа** | Внутренний номер CRM |
| **Счёт / УПД / Акт / Счёт-фактура** (заказчик и перевозчик) | Подписи загруженных или сгенерированных документов; клик — предпросмотр |
| **Заявка заказчика / перевозчика** | Заявки из печатных форм мастера заказа |
| **Договор с заказчиком / перевозчиком** | Договоры из шаблонов |
| **Транспортные документы** | ТТН, CMR, упаковочные листы и т.п. |
| **Статус ЭТрН**, **External ID ЭТрН** | Поля журнала ЭТрН |
| **Прочее** | Документы типа «Прочее» |

Подсказка внизу таблицы: **двойной клик по строке** открывает полный список документов заказа (то же окно, что на карточке заказа).

---

## 4. Открытие и просмотр документа

1. **Одиночный клик** по подписи в ячейке (например, «Счёт № …»):
   - для **загруженного файла** — предпросмотр или скачивание (PDF, изображения, Office);
   - для **заявки / договора из шаблона** — экран печатной формы (редактирование черновика, печать, выгрузка).
2. **Двойной клик по строке** — модальное окно **Документы заказа**: все файлы и формы по этому заказу, загрузка, удаление (если есть право).

Документы, добавленные в **мастере заказа** (вкладка «Документы»), автоматически попадают в реестр — отдельно дублировать не нужно.

---

## 5. Добавить документ из реестра

1. Нажмите **Добавить документ** (в шапке или из контекста таблицы, если доступно).
2. Заполните поля:

| Поле | Обязательно | Пояснение |
| --- | --- | --- |
| **Заказ** | Да | Заказ из списка доступных вам |
| **Сторона** | Да | Заказчик / Перевозчик / Внутренний |
| **Тип документа** | Да | Счёт, УПД, Акт, Договор, ЭТрН, CMR и др. |
| **Статус** | Да | Черновик, Ожидает, Подписан, Отправлен |
| **Номер документа** | Нет | Для учёта и подписи в таблице |
| **Дата документа** | Нет | |
| **Файл** | Да при создании | PDF, DOC/DOCX, XLS/XLSX, JPG/PNG/WebP |

3. Файл можно **перетащить** в зону загрузки или выбрать кнопкой **Выбрать файл**.
4. При превышении лимита размера появится предупреждение (лимиты задаются в настройках CRM).
5. **Добавить** — документ привязывается к заказу и отображается в соответствующей колонке реестра.

Редактирование существующей записи: изменить метаданные и при необходимости заменить файл (через карточку заказа или реестр, если доступна операция редактирования).

---

## 6. Типы документов

| Тип в форме | Когда использовать |
| --- | --- |
| Счёт | Счёт на оплату заказчику или от перевозчика |
| УПД | Универсальный передаточный документ |
| Акт | Акт выполненных работ / оказанных услуг |
| Счёт-фактура | НДС-документ |
| Договор | Подписанный или черновой договор (файл) |
| Транспортная накладная | Бумажная ТТН |
| **ЭТрН** | Электронная транспортная накладная (журнал на отдельной вкладке) |
| CMR | Международная накладная |
| Упаковочный лист | Сопроводительные документы груза |
| Таможенная декларация | ВЭД |
| Прочее | Всё, что не попало в другие типы |

**Заявки** и **договоры из шаблонов** создаются в **мастере заказа** (печатные формы), а не через «Добавить документ» — в реестре они отображаются в колонках «Заявка …» / «Договор …».

---

## 7. Статусы документа

| Статус | Смысл |
| --- | --- |
| **Черновик** | Файл загружен, учёт не завершён |
| **Ожидает** | Ждёт подписи или отправки |
| **Подписан** | Документ согласован |
| **Отправлен** | Передан контрагенту или в ЭДО |

Статус помогает фильтровать работу бухгалтерии и логистики; на права доступа к файлу он не влияет.

---

## 8. Журнал ЭТрН

1. Переключитесь на вкладку **Журнал ЭТрН**.
2. В таблице останутся заказы с хотя бы одним документом типа **ЭТрН**.
3. Используйте колонки **Статус ЭТрН** и **External ID ЭТрН** для сверки с внешней системой обмена.

Загрузка нового ЭТрН — через **Добавить документ**, тип **ЭТрН**, сторона по ситуации (часто перевозчик или внутренний).

---

## 9. Связь с заказом и уведомлениями

- Документы всегда привязаны к **одному заказу**.
- При закрытии заказа CRM может напоминать о недостающих закрывающих документах (если включены уведомления в вашей установке).
- Компенсации и финансовые сводки учитывают загруженные документы там, где это настроено в модуле финансов.

Подробнее о документах **внутри карточки заказа** см. инструкцию **Мастер заказов**.

---

## 10. Частые вопросы

**Не вижу заказ в списке при добавлении документа**  
Проверьте доступ к заказам: вы видите только «свои» заказы, если у роли ограничена видимость.

**Колонка пустая, а документ есть в карточке заказа**  
Обновите страницу. Убедитесь, что тип документа соответствует колонке (например, «Прочее» не попадёт в «Счёт заказчику»).

**Клик по заявке открывает не файл, а форму**  
Это ожидаемо: заявки и договоры из шаблонов — печатные формы, а не загруженные PDF.

**Раздел «Документы» не отображается в меню**  
Администратору нужно включить область видимости **«Документы»** в настройках роли.

## 11. Краткая шпаргалка

| Действие | Как |
| --- | --- |
| Открыть реестр | Меню → **Документы** |
| Все файлы заказа | Двойной клик по строке |
| Просмотр одного документа | Клик по подписи в ячейке |
| Загрузить PDF/скан | **Добавить документ** |
| Только ЭТрН | Вкладка **Журнал ЭТрН** |
| Заявка из шаблона | Мастер заказа → печатные формы |
