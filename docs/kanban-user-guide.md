# Канбан — инструкция для пользователя

Документ описывает доску задач: колонки по статусам, перетаскивание карточек и связь со списком **Задачи**.

Подробнее о полях, чеклисте и SLA: [Задачи](tasks-user-guide.md).

---

## 1. Как открыть раздел

1. В меню **Планирование → Канбан** (или пункт **Канбан** в боковой панели).
2. Откроется доска с колонками по статусам задач.

> Область видимости **«Канбан»** — для просмотра доски. Чтобы **перетаскивать** карточки и **создавать** задачи, нужна также область **«Задачи»**.

---

## 2. Структура доски

### Колонки (слева направо)

| Колонка | Статус задачи |
| --- | --- |
| 1 | **Новая** |
| 2 | **В работе** |
| 3 | **На проверке** |
| 4 | **Завершена** |
| 5 | **Отложена** |

В каждой колонке — карточки задач, которые сейчас в этом статусе.

### Карточка задачи

На карточке отображаются:

- **Номер** задачи (TSK-…)
- **Название**
- **Ответственный**
- **Лид** (если привязан)
- **Срок**
- Метка **«срочно»** — для приоритета **Критичный**

---

## 3. Основные действия

### Перетаскивание (drag-and-drop)

1. Зажмите карточку мышью.
2. Перетащите в другую колонку.
3. Отпустите — **статус задачи изменится** автоматически.

Требуется область видимости **«Задачи»**. Без неё доска только для просмотра.

### Открыть задачу

- **Двойной клик** по карточке — или кнопка **«Открыть в задачах»** (переход в список с открытой карточкой).
- В карточке доступны чеклист, комментарии, вложения, история.

### Создать задачу

Кнопка **Создать задачу** на доске → переход в раздел **Задачи** с открытой формой создания.

---

## 4. Настройка вида

### Ширина колонок

Потяните **правый край** заголовка колонки — ширина сохраняется **в браузере** (локально для вашего компьютера).

### Прокрутка

При большом числе колонок или карточек используйте **горизонтальную прокрутку** доски.

---

## 5. Какие задачи попадают на доску

- Те же записи, что в списке **Задачи**.
- Учитываются **права видимости**:
  - «Только свои» — карточки, где вы ответственный;
  - «Все» — все задачи в системе.

Фильтры списка задач и Канбан показывают согласованный набор записей (с учётом роли).

---

## 6. Связь статусов с лидом

Если у задачи указан **лид**, при перетаскивании карточки и смене статуса может обновляться **статус лида** (см. таблицу в [руководстве по задачам](tasks-user-guide.md)).

---

## 7. Канбан vs список «Задачи»

| Возможность | Канбан | Список «Задачи» |
| --- | --- | --- |
| Обзор этапов работы | ✓ наглядно | таблица |
| Смена статуса перетаскиванием | ✓ | через колонку / меню |
| Массовые действия | — | ✓ чекбоксы |
| Поиск и фильтры | ограниченно | ✓ полный набор |
| Чеклист, комментарии | в карточке | в карточке |
| Inline-редактирование в таблице | — | ✓ |

**Рекомендация:** планируйте и распределяйте работу на **Канбане**; детальную работу, массовые операции и поиск — в **Задачах**.

---

## 8. Типичные сценарии

**Ежедневный стендап.** Колонка «Новая» → перетащить в «В работе» по мере взятия в работу.

**Сдача на проверку.** «В работе» → «На проверке»; руководитель → «Завершена».

**Отложить.** Перетащить в «Отложена», когда ждёте ответа клиента.

**Срочное.** Критичный приоритет — карточка с меткой «срочно», держите в «В работе» или «На проверке».

---

## 9. Частые вопросы

**Не перетаскивается.** Нужна область **«Задачи»**, не только «Канбан».

**Карточки не те.** Проверьте, не ограничена ли роль «только свои задачи».

**После перетаскивания статус лида изменился.** Это нормально при привязке задачи к лиду.

**Ширина колонок сбросилась.** Настройка хранится в браузере; другой браузер или очистка данных — снова настроить вручную.
