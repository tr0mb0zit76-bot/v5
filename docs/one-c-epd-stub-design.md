### ЭТрН — поля для болванки

В `$metadata` **обязателен только** `Ref_Key` (на create не шлём). Остальное `Nullable=true`.

Полезные реквизиты шапки:

| Поле | Назначение |
| --- | --- |
| `Date`, `Number`, `Posted`, `DeletionMark` | стандарт документа |
| `Комментарий` | `CRM {number} (id N)` |
| `Организация_Key` | наша компания |
| `ТитулГрузоотправителяТранспортнаяНакладнаяНомер/Дата` | номер/дата ТН |
| `СсылкаТитулГрузоотправителяЗаказчик` (+ `_Type`) | заказчик |
| `СсылкаТитулГрузоотправителяГрузоотправитель` (+ `_Type`) | ГО |
| `СсылкаТитулГрузоотправителяГрузополучатель` (+ `_Type`) | ГП |
| `СсылкаТитулГрузоотправителяПеревозчик` (+ `_Type`) | перевозчик |
| `ТекущийТитул`, `ТекущийПолученныйТитул` | статусы титулов |
| `ИдентификаторГрузоотправителя/Грузополучателя/Перевозчика` | идентификаторы ЭПД |

**Нет** `Контрагент_Key` (в отличие от реализации). Титулы перевозчика/получателя — отдельные группы полей (`ТитулПеревозчикаПриемка*`, `ТитулГрузополучателя*`, …).

Конфиг:

- `ONE_C_ODATA_ETRN_PATH` → `/odata/standard.odata/Document_ЭлектроннаяТранспортнаяНакладная` ✅
- `ONE_C_ODATA_EXPEDITION_RECEIPT_PATH` → placeholder до появления EntitySet

Mapper/client: `OneCEpdStubMapper` + `OneCBpClient::epdWriteBody` пишут стороны в `СсылкаТитулГрузоотправителя*`. Следующий шаг — пробный POST на тестовом заказе (не на проде без согласования).

## Чек-лист

| Слот | `slot_kind` | `is_required` | `party` | Fulfillment |
| --- | --- | --- | --- | --- |
| Бумажная ТН/CMR/ТСД | `waybill` | true | carrier | файл waybill\|cmr (без etrn) |
| ЭТрН | `etrn` | true | carrier | файл `etrn` sent/signed **или** EDO-ack `etrn` |
| Экспедиторская расписка | `expedition_receipt` | **false** | customer | файл / EDO-ack; не блокирует закрытие сделки |

`OrderStatusService` учитывает только правила с `is_required !== false`.

## Границы

- Отдельный `OneCEpdStubSyncService` — **не** ветки в `OneCRealizationSyncService`.
- `accounting_handoff` только у реализации.
- Cleanup при удалении заказа: непроведённые etrn / expedition_receipt, как реализация.
