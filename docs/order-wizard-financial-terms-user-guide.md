# Финансовые условия в мастере заказов

Инструкция по вкладке **Финансы** в мастере заказа: оплата заказчика, перевозчиков и подрядчиков, транши, плановые даты и связь с графиком оплат.

**См. также:** [Мастер заказов](order-wizard-user-guide.md) · [Документы](documents-user-guide.md) · [График оплат (техн.)](payment-schedule-architecture.md)

---

## 1. Где настраивать

1. Откройте заказ (**Заказы** → карточка или **Новый заказ**).
2. Перейдите на вкладку **Финансы**.
3. Блоки на вкладке:
   - **Оплата клиентом** — цена, валюта, форма оплаты, график траншей;
   - **Затраты по исполнителям** — ставка и условия по каждому перевозчику с маршрута;
   - **Дополнительные затраты** — подрядчики (экспедирование, страхование и т.п.);
   - **Страховка**, **бонус**, **KPI и маржа** — влияют на расчёт маржи.

Для первого сохранения нового заказа достаточно **цены клиента > 0** (см. «Мастер заказов», раздел про минимальный черновик).

---

## 2. Оплата клиентом

### Обязательные поля

| Поле | Что указать |
| --- | --- |
| **Цена клиента** | Сумма перевозки для заказчика (> 0 для сохранения) |
| **Валюта** | RUB / USD / EUR и др. |
| **Форма оплаты** | С НДС / без НДС / нал |

### График траншей

Условия оплаты задаются **траншами** (до **10** на одну сторону — заказчик или перевозчик).

Переключатель в блоке:

- **Один транш** — 100 % одной строкой (типичный вариант «оплата по оригиналам после выгрузки»).
- **Несколько траншей** — несколько долей (например, 30 % аванс + 70 % по документам).

У каждого транша:

| Поле | Смысл |
| --- | --- |
| **%, доля** | Процент от суммы стороны; суммы в рублях пересчитываются автоматически |
| **Сумма** | Можно править вручную; процент подстроится при следующей синхронизации |
| **Сдвиг, дн** | Сколько дней от **якоря** (может быть отрицательным — «за N дней до…») |
| **Тип дней** | **Календарные** или **Банковские** (пн–пт) |
| **Якорь** | Точка отсчёта сдвига (см. таблицу ниже) |
| **Событие** | Когда считается наступление оплаты (см. таблицу ниже) |

Кнопка **Добавить транш** доступна в режиме «Несколько траншей», пока не достигнут лимит 10.

### Якорь (точка отсчёта сдвига)

| Значение в UI | Когда используется |
| --- | --- |
| Первая погрузка (план в маршруте) | Сдвиг от плановой/фактической первой погрузки |
| Последняя выгрузка (план) | Сдвиг от последней выгрузки на маршруте |
| Прохождение границы (план) | Транзит, таможня |
| Дата заказа | От даты в шапке заказа |
| Дата погрузки / выгрузки (в заказе) | От колонок заказа, если маршрут ещё пустой |

### Событие (базис оплаты)

| Значение в UI | Когда наступает оплата |
| --- | --- |
| **По сканам** | После прикрепления пакета транспортных документов (ТН / CMR / ЭТрН) со статусом «Отправлен» или «Подписан» |
| **По сканам + квиток** | То же + отметка о получении трека заказчиком в гриде документов |
| **По оригиналам** | После закрывающих документов (УПД, акт, счёт-фактура) и транспортного пакета |
| **При погрузке** | По фактической или плановой дате погрузки |
| **При выгрузке** | По фактической или плановой дате выгрузки |

Для **по сканам** / **по оригиналам** плановая дата в графике оплат появится после появления нужных документов в заказе.

### Сводка для договора

Под траншами — текст **«Сроки и условия оплаты»** для печатных форм и договора.

- Заполняется **автоматически** из траншей при изменении полей.
- Можно **отредактировать вручную** — тогда автообновление не перезапишет текст, пока вы снова не смените режим траншей или не нажмёте логику сброса (смена «один / несколько траншей» сбрасывает ручную правку сводки).

---

## 3. Затраты по исполнителям (перевозчики)

Строки появляются из вкладки **Маршрут**. У каждого плеча — **ставка перевозчика** и тот же блок **траншей**, что у заказчика.

- **Подтянуть из этапов** — обновить список перевозчиков по текущему маршруту.
- Условия по умолчанию подставляются из карточки контрагента (**дефолтный график перевозчика**), если он заполнен.
- Сумма траншей перевозчика считается от **его** ставки, не от цены клиента.

---

## 4. Дополнительные затраты (подрядчики)

Расходы на экспедирование, страхование, таможню и т.п.: контрагент, сумма, дата, **условия оплаты** (тот же вид траншей).

Строки попадают в общий **График оплат** с пометкой стороны **подрядчик**.

---

## 5. Связь с графиком оплат

После **Сохранить** заказа система пересобирает раздел **Финансы → График оплат** (и грид на странице **Финансы**):

- одна строка графика ≈ один транш (заказчик + каждый перевозчик + подрядчики);
- колонка **План** — расчётная дата в формате **дд.мм.гггг**;
- **Факт** и статус (**Ожидает** / **Просрочен** / **Оплачен**) сохраняются при изменении траншей, если совпадают сторона и порядковый номер транша.

При смене цены или условий проверьте график: плановые даты могут сдвинуться, просрочки пересчитаются автоматически.

## 6. Типовые схемы

### 100 % по оригиналам после выгрузки

- Режим **Один транш**, 100 %.
- Событие: **По оригиналам**.
- Якорь: **Последняя выгрузка**, сдвиг **0** (или +N календарных дней по договору).

### 50 % аванс по сканам + 50 % по оригиналам

- Режим **Несколько траншей**.
- Транш 1: 50 %, событие **По сканам**, якорь **Первая погрузка**, сдвиг 0.
- Транш 2: 50 %, событие **По оригиналам**, якорь **Последняя выгрузка**, сдвиг +5 **банковских** дней.

### Оплата перевозчику при выгрузке

- В блоке перевозчика: один транш 100 %, событие **При выгрузке**, сдвиг 0.

---

## 7. Дефолты из карточки контрагента

В карточке заказчика / перевозчика (вкладка с условиями) можно задать **график по умолчанию**. При выборе контрагента в новом заказе условия **подставятся** в мастер; их можно изменить только для этого заказа.

---

## 8. Частые вопросы

| Ситуация | Что проверить |
| --- | --- |
| Плановая дата в графике пустая | Нет факта/плана по маршруту или ещё нет документов для выбранного **события** |
| Дата «по сканам» не двигается | Нет транспортного пакета (ТН/CMR/ЭТрН) в статусе «Отправлен» / «Подписан» |
| «По сканам + квиток» не срабатывает | В гриде документов не заполнена дата трека для нужной стороны |
| Просрочка в pipeline / финансах | Плановая дата прошла, оплата не отмечена — строка графика в статусе **Просрочен** |
| Сумма траншей ≠ цене | Проверьте, что сумма **%** по траншам = 100 % (система округляет суммы) |

---

## 9. KPI и маржа

Поля **KPI** и **маржа** на вкладке **Финансы** пересчитываются автоматически при изменении цены клиента, ставок перевозчиков и дополнительных затрат (с небольшой задержкой после ввода).
