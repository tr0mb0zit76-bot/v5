# Мастер заказов — инструкция для пользователя

Документ описывает, как создать и вести заказ в CRM: от минимально заполненной карточки до документов, печатных форм и автоматических статусов.

**См. также:** [Документы](documents-user-guide.md) · [Ассистенты CRM](ai-assistants-user-guide.md) · [Регламент оформления заявки и базовых условий](order-application-basic-terms-regulation.md)

---

## 1. Как открыть мастер

1. В боковом меню выберите **Заказы**.
2. На списке заказов нажмите **Новый заказ**.
3. Откроется мастер с заголовком **Новый заказ** и шестью вкладками.

После первого сохранения система перенаправит вас в карточку существующего заказа (**Карточка заказа**). Дальнейшие правки сохраняются той же кнопкой **Сохранить**.

## 2. Минимальный «черновик» заказа — что обязательно заполнить

Отдельного режима «сохранить как черновик без проверок» нет: и создание, и обновление заказа проходят одни и те же базовые проверки.

### Четыре обязательных поля

| №   | Где в интерфейсе               | Что указать                                     |
| --- | ------------------------------ | ----------------------------------------------- |
| 1   | **Основное** → **Контрагент**  | Заказчик (поиск по названию или ИНН)            |
| 2   | **Основное** → **Дата заказа** | Подставляется сегодняшняя дата — можно оставить |
| 3   | **Маршрут** → **Перевозчик**   | Хотя бы один перевозчик на любом плече          |
| 4   | **Финансы** → **Цена клиента** | Сумма **больше 0**                              |

Если чего-то не хватает, над вкладками появится подсказка:

> Для сохранения заполните: Заказчик, Дата заказа, Перевозчик, Цена клиента.

При нажатии **Сохранить** мастер сам переключит вкладку на первую с ошибкой: **Основное** → **Маршрут** → **Финансы**.

### Быстрый сценарий «записать заказ за 2 минуты»

1. **Основное** — выберите заказчика в поле **Контрагент**.
2. **Маршрут** — в первом плече найдите и выберите **Перевозчик** (поле поиска, как у заказчика). Маршрут, адреса и даты можно не заполнять.
3. **Финансы** — укажите **Цену клиента**, например `100000`.
4. Нажмите **Сохранить** (кнопка в шапке, доступна на любой вкладке).

После сохранения откроется карточка заказа с присвоенным номером. Остальные данные (груз, маршрут, документы, нормативы) можно дозаполнить позже.

### Что **не** обязательно для первого сохранения

- Своя компания, расчётный счёт
- Адреса погрузки и выгрузки, плановые даты
- Грузовые позиции
- График оплат, дополнительные затраты, страховка, бонус
- Нормативы и штрафы
- Документы и печатные формы

## 3. Обзор интерфейса

### Шапка (на всех вкладках)

| Элемент                        | Назначение                                                                             |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| **Внутренняя / Международная** | Тип перевозки. Влияет на поля таможни на маршруте и на подбор шаблонов печатных форм   |
| **Статус заказа**              | Рассчитывается автоматически по фактическим датам, документам и оплатам (см. раздел 8) |
| **Сохранить**                  | Записывает все вкладки разом                                                           |

### Вкладки

| Вкладка                | Для чего                                                             |
| ---------------------- | -------------------------------------------------------------------- |
| **Основное**           | Заказчик, своя компания, дата, номер, сводка по финансам             |
| **Маршрут**            | Плечи, перевозчики, точки маршрута, фактические даты, свой транспорт |
| **Груз**               | Грузовые позиции, вес, упаковка, распределение по перевозчикам       |
| **Финансы**            | Цена клиента, затраты на перевозчиков, доп. расходы, KPI             |
| **Нормативы / штрафы** | Срыв, простой, штрафы для заказчика и по плечам                      |
| **Документы**          | Печатные формы, прикрепление файлов, учёт обязательных документов    |

## 4. Вкладка «Основное»

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-31-17-image.png)

### Своя компания и счёт

- **Своя компания** — от какого юрлица ведётся заказ. Не обязательна для сохранения, но нужна для корректного подбора шаблонов документов и реквизитов в печатных формах.
- **Расчётный счёт своей компании** — появляется, если у выбранной компании несколько счетов. Можно оставить «Основной (по умолчанию)».

### Контрагент (заказчик)

- Начните вводить название или ИНН — откроется список совпадений.
- Кнопка **Новый контрагент** — быстрое создание заказчика без выхода из мастера.

### Дата и номер

- **Дата заказа** — обязательна (по умолчанию сегодня).
- **Номер** — можно оставить пустым: система сгенерирует при сохранении.

### Клиентская заявка (если плеч несколько)

При нескольких плечах маршрута доступен режим:

- **Одна заявка** — все плечи в одном документе для заказчика;
- **Разбить по плечам** — отдельная заявка на каждое плечо.

### Финансовая сводка

Блок показывает цену клиента, себестоимость, маржу и KPI по мере заполнения вкладки **Финансы**.

### Особые отметки

Произвольный текст для внутреннего использования (не влияет на сохранение).

## 5. Вкладка «Маршрут»

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-33-01-image.png)

### Плечи маршрута

- По умолчанию создаётся одно плечо (**Плечо 1**).
- Кнопка **Добавить плечо** — для мультимодальных или составных перевозок.

### Перевозчик на плече

- Режим **Один исполнитель** — один перевозчик на всё плечо.
- Режим **Несколько исполнителей** — до четырёх перевозчиков на одном плече (нужно указать минимум двух).

Поиск перевозчика — так же, как заказчика. Кнопка **+ Новый** создаёт контрагента типа «перевозчик».

### Свой транспорт

Если перевозчик — ваша компания с автопарком:

- включите **Свой транспорт**;
- выберите **Авто** и **Водителя** из справочника.

### Фактические даты

- **Факт. погрузка** и **Факт. выгрузка** на плече участвуют в автоматическом статусе заказа (см. раздел 8).

### Точки маршрута

На каждом плече — точки **Погрузка** и **Выгрузка** (можно добавлять и менять порядок):

- адрес (с подсказками DaData), город;
- плановая и фактическая дата/время;
- контакты отправителя и получателя.

Для корректной подстановки города в маршрут необходимо вставить в поле "Адрес" адрес, дождаться подсказки DaData, выбрать нужную и "кликнуть" по ней. Если город не определился либо определился некорректно, его можно внести вручную. Функционал на текущий момент не поддерживает автоопределение адресов за пределами России.

Для **международной** перевозки доступны точки **Пересечение границы** с полями **Код поста**, **СВХ**, **Адрес СВХ**.

### Портал перевозчика

После **первого сохранения** заказа у перевозчика появляется возможность отправить приглашение в личный кабинет (кнопка на плече). До сохранения заказа портал недоступен.

## 6. Вкладка «Груз»

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-51-04-image.png)

### Грузовые позиции

Можно добавить несколько позиций. Для каждой указываются:

- наименование, тип груза, вес, количество мест;
- упаковка, ТН ВЭД, класс опасности;
- габариты (длина / ширина / высота), объём, описание;
- тип погрузки, кузова, прицепа (справочники ATI).

### Объявленная стоимость груза

Общая сумма для страхования и документов — по желанию.

### Распределение груза между перевозчиками

Если на маршруте несколько перевозчиков (режим «Несколько исполнителей» или несколько плеч), появляется таблица распределения веса и мест. Перед сохранением вес и места должны быть распределены полностью — иначе система не даст сохранить заказ.

## 7. Вкладка «Финансы»

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-52-07-image.png)

### Оплата клиентом

- **Цена клиента** — обязательна (> 0).
- **Валюта**, **форма оплаты** (с НДС / без НДС / нал).
- **График оплат** — транши с датами; суммы процентов должны давать 100 %.

### Затраты по исполнителям

Строки по перевозчикам с маршрута. Кнопка **Подтянуть из этапов** синхронизирует список с вкладкой **Маршрут**.

### Дополнительные затраты

Расходы на подрядчиков (экспедирование, страхование и т.п.): контрагент, дата, сумма, условия оплаты.

### Страховка и бонус

Дополнительные суммы; участвуют в расчёте маржи.

### KPI и маржа

Процент KPI и маржа пересчитываются автоматически при изменении финансовых полей (с небольшой задержкой после ввода).

## 8. Статусы заказа

Статус в шапке **не выбирается вручную** при обычной работе — система определяет его по данным заказа.

| Статус          | Когда появляется                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------- |
| **Новый заказ** | Заказ создан, фактическая погрузка ещё не зафиксирована                                                     |
| **Выполняется** | Есть фактическая дата погрузки (на точке маршрута или на плече)                                             |
| **Документы**   | Есть фактическая дата выгрузки                                                                              |
| **Оплата**      | Выгрузка выполнена, но не все обязательные документы собраны — или документы есть, но нет отметок об оплате |
| **Завершено**   | Обязательные документы на месте, отмечены оплаты заказчика, перевозчика и выплата менеджеру                 |

Специальные статусы (обычно только у руководителя / администратора):

- **Срыв** — срыв перевозки;
- **Отменена** — заказ отменён.

Под статусом при наведении показывается подсказка: *«Рассчитывается автоматически по фактическим датам плеч, документам и оплатам»*.

## 9. Вкладка «Документы»

> **Полная инструкция:** [documents-user-guide.md](documents-user-guide.md) — реестр, печатные формы, чек-лист, intake, портал перевозчика.

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-53-56-image.png)

Здесь два разных понятия «черновика»:

1. **Черновик заказа** — сама карточка заказа с минимальным набором полей (раздел 2).
2. **Черновик печатной формы** — сгенерированный DOCX по шаблону до финального PDF.

### 9.1. Печатные формы

**До первого сохранения заказа** создавать печатные формы нельзя — сначала сохраните карточку.

**После сохранения:**

1. В зелёном блоке (**заказчик**) или красном (**перевозчик**) выберите **Шаблон** из списка.
2. Нажмите **Создать в карточке**.
3. В списке ниже появится документ со статусом workflow (черновик → согласование → финальный PDF).

Доступные действия с черновиком:

- **Предпросмотр** / **Скачать черновик DOCX**
- **Отправить на согласование** → **Согласовать** / **Отклонить**
- **Загрузить финальный PDF**
- **Пересоздать черновик** / **Удалить черновик**

Выбранный шаблон в каждом слоте сохраняется вместе с заказом (кнопка **Сохранить** в шапке).

#### Как система выбирает шаблоны в списке

Список фильтруется по текущему заказу:

| Условие в шаблоне (Настройки → Шаблоны) | Должно совпасть с заказом                                                          |
| --------------------------------------- | ---------------------------------------------------------------------------------- |
| Своя компания                           | Та же **Своя компания** на вкладке «Основное», либо шаблон «для любой»             |
| Тип перевозки                           | **Внутренняя** ↔ внутрироссийская; **Международная** ↔ ВЭД; «любая» ↔ оба варианта |
| Сторона                                 | Заказчик / перевозчик (шаблон «внутренний» подходит обеим сторонам)                |
| Контрагент                              | Конкретный перевозчик или заказчик, если шаблон к нему привязан                    |

Шаблон **по умолчанию** подставляется автоматически — приоритет у наиболее точного совпадения (компания + тип перевозки + контрагент).

Настройка шаблонов: **Настройки → Шаблоны печати**.

### 9.2. Прикрепление подписанных файлов

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-55-42-image.png)

- Перетащите файл в зону **Прикрепить файл** или нажмите кнопку.
- Укажите сторону (заказчик / перевозчик / подрядчик), тип документа, при необходимости плечо и номер.
- Файл сразу попадает в реестр документов (не требует отдельного сохранения заказа).

**Распознавание заявки клиента** (PDF → поля мастера) — на экране **Новый заказ**, блок «Заполнить из заявки», не на этой вкладке. См. [documents-user-guide.md](documents-user-guide.md#4-заполнить-из-заявки-заказчика-новый-заказ).

Допустимые форматы: PDF, DOC, DOCX, XLS, XLSX, JPG, PNG и др. (см. подсказку при загрузке). Есть ограничение по размеру файла.

### 9.3. Учёт документов

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-56-14-image.png)

Таблица **Учёт документов** — чек-лист обязательных документов для перехода к статусам **Оплата** и **Завершено**.

Галочка ставится, когда:

- загружен подписанный файл нужного типа, **или**
- печатная форма доведена до финального PDF.

## 10. Вкладка «Нормативы / штрафы»

![](C:\Users\Руслан\AppData\Roaming\marktext\images\2026-05-30-10-56-34-image.png)

Не обязательна для сохранения. Здесь задаются:

- для **заказчика**: суммы срыва, простоя, штрафа; валюты; текст условий; нормативные часы (погрузка, таможня, выгрузка);
- **по каждому плечу / перевозчику** — те же поля отдельно.

Используется в договорной работе и печатных формах, если в шаблоне есть соответствующие переменные.

## 11. Что может помешать сохранению

| Ситуация                                            | Что делать                                                                                              |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Не заполнены 4 обязательных поля                    | См. раздел 2; следуйте подсветке и сообщению над вкладками                                              |
| **Лимит задолженности** у заказчика                 | Новый заказ создать нельзя — сообщение под полем контрагента. Обратитесь к финансовому контролёру       |
| Несколько исполнителей на плече, указан только один | Добавьте второго перевозчика или верните режим «Один исполнитель»                                       |
| Не распределён груз между перевозчиками             | Вкладка **Груз** → таблица распределения                                                                |
| График оплат: проценты ≠ 100 %                      | Вкладка **Финансы** → исправьте транши                                                                  |
| Авто/водитель не принадлежат выбранному перевозчику | Выберите технику из списка этого перевозчика                                                            |
| Заказ **заблокирован для редактирования**           | Все печатные формы по workflow финализированы — правки только через администратора / отмену финализации |
| Ошибка загрузки документа                           | Проверьте размер и формат файла                                                                         |

## 12. Права доступа (кратко)

| Роль                                                     | Возможности                                                                                               |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Администратор / руководитель**                         | Полное редактирование любых заказов, статус «Срыв»                                                        |
| **Менеджер**                                             | Редактирование своих заказов; после финализации всех печатных форм карточка может стать только для чтения |
| **Диспетчер, бухгалтер, делопроизводитель, наблюдатель** | Доступ к модулю заказов согласно настройкам роли                                                          |

Если кнопка **Сохранить** неактивна — нет прав на редактирование или заказ заблокирован.

## 13. Типовой рабочий процесс от А до Я

```
1. Новый заказ
   └─ Минимум: заказчик + перевозчик + цена → Сохранить

2. Детализация
   └─ Основное: своя компания, тип перевозки (шапка)
   └─ Маршрут: адреса, плановые даты
   └─ Груз: позиции
   └─ Финансы: ставки перевозчикам, график оплат
   └─ Сохранить

3. Документы
   └─ Выбор шаблона → Создать в карточке → черновик DOCX
   └─ Согласование → финальный PDF
   └─ Или: прикрепить уже подписанный скан

4. Исполнение
   └─ Факт. погрузка → статус «Выполняется»
   └─ Факт. выгрузка → «Документы»

5. Закрытие
   └─ Все пункты чек-листа документов ✓
   └─ Отметки об оплатах
   └─ Статус «Завершено»
```

## 14. Частые вопросы

**Можно ли сохранить заказ без маршрута и груза?**  
Да, если указаны заказчик, дата, перевозчик и цена клиента.

**Почему не вижу кнопку «Создать в карточке»?**  
Сначала сохраните заказ. Для документов перевозчика на плече должен быть выбран перевозчик.

**Почему в списке шаблонов пусто?**  
Проверьте: тип перевозки (шапка), своя компания, активность шаблона в настройках, наличие загруженного DOCX в шаблоне.

**Нужно ли сохранять заказ после прикрепления файла в «Документы»?**  
Нет — прикрепление идёт сразу в реестр. Сохранение заказа нужно для выбора шаблонов и полей на других вкладках.

**Чем «черновик DOCX» отличается от сохранённого заказа?**  
Заказ — запись в CRM. Черновик DOCX — сгенерированный файл заявки/договора по шаблону; живёт в workflow документов и не заменяет сохранение карточки.
